01 — selected work

Projects

Open-source security tooling I design and ship — reconnaissance, scanning and reporting, mostly in Python.

01

KitoAi

AI-powered penetration-testing assistant. An LLM-driven plan → execute → analyze agent that orchestrates nmap, subfinder, nuclei, katana, ffuf, sqlmap and nikto, parses HackerOne / Bugcrowd scopes, scores findings with CVSS v3.1 and produces HackerOne-style reports. Ships an interactive CLI, a headless runner and a FastAPI dashboard.

Python FastAPI LLM agents Bug bounty 4★ · Inspect
02

Subdomain Recon

Attack-surface reconnaissance toolkit. Five phases in one command: crt.sh passive enumeration plus DNS brute-force with wildcard protection, concurrent live-host probing, TCP port scanning, technology fingerprinting and banner grabbing, and JSON + self-contained HTML reports.

Python asyncio Recon Reporting 12★ · Inspect
03

VulnScanner

Automated web vulnerability scanner: HTTP security-header analysis (CSP, HSTS, X-Frame-Options…), socket-based TCP port scanning with service detection, OWASP-style checks for directory discovery, cookie security and injection / XSS reflection, risk scoring and corporate PDF / TXT reports. CI-tested on Python 3.9 – 3.13.

Python OWASP PDF reports Automation 2★ · Inspect
04

CyberDelve

Keyless cyber-threat news aggregator. Pulls 41 feeds (BleepingComputer, The Hacker News, Krebs, CISA, CrowdStrike, Unit42…), tracks CVEs, KEV and ransomware activity, and ships trending panels, JSON output, a Telegram bot, Discord / Slack webhooks and a local web dashboard.

Python Threat intel Telegram Dashboard 2★ · Inspect
